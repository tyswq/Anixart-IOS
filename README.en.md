The client is based on [arigandores/anix](https://github.com/arigandores/anix): the same endpoints, request
signing and video parsers. It is not affiliated with or endorsed by the Anixart developers.

## Installation

The app is unsigned, so it is installed by sideloading. A Windows or Mac computer is needed only for the installation.

1. Download `Anix-<version>.ipa` from the [Releases](https://github.com/tyswq/Anixart-IOS/releases/latest) page.
2. Install [Sideloadly](https://sideloadly.io). On Windows you need iTunes and iCloud downloaded from Apple's website, not from the Microsoft Store.
3. Connect your iPhone with a cable and tap Trust on the iPhone.
4. Drag the `.ipa` into the Sideloadly window, enter your Apple ID and click **Start**.
5. Turn on Developer Mode: **Settings → Privacy & Security → Developer Mode**, then restart the iPhone.
6. Trust the profile: **Settings → General → VPN & Device Management** → your Apple ID → **Trust**.

Updating: install the new `.ipa` over the old one the same way; your login and data are kept.

> A free Apple ID signs the app for **7 days**, after that it has to be reinstalled. [AltStore](https://altstore.io) and
> [SideStore](https://sidestore.io) can renew the signature automatically. A paid developer account signs for a year.

The minimum system is iOS 18. On iOS 26 the interface uses Liquid Glass; on iOS 18–25 it uses a frosted material instead.

## Building it yourself

```sh
brew install xcodegen
xcodegen generate
open Anix.xcodeproj
```

Choose your own signing team and run. Xcode 26 is required.

## Project structure

```
Anix/
  AnixApp.swift         entry point, root screen and tabs
  Core/                 API, models, request signing, login, settings, stores
  UI/                   screens: home, release, search, library, profile, comments, settings
  Player/               AVPlayer-based player and video source parsing
  Resources/en.lproj/   English localization (keys are the Russian source strings)
  Assets.xcassets/      icon and resources
project.yml             project description for XcodeGen
CHANGELOG.md            changelog (Russian); CHANGELOG.en.md is the English one
README.en.md            this file
```

The project is generated by XcodeGen; there is no `.xcodeproj` in the repository.

## FAQ

**Covers don't load.** Turn on **Settings → Alternative connection**. Images then go through a mirror,
which helps when your provider blocks some CDN addresses.

**The app stopped opening.** A week has passed and the free Apple ID signature expired. Reinstall the `.ipa`.

**Video from some source doesn't work.** Kodik and AniLibria play directly. The other sources
open in the built-in web player, and how well it works depends on the source itself.

**Part of the text is still in Russian in English mode.** The release description, genres and status are translated by
the built-in iOS translator. On first launch the system may offer to download a language pack. Comments and episode
names are not translated.
