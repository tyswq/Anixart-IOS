# Anix для iOS

Неофициальный iOS-клиент Anixart на SwiftUI с дизайном **Liquid Glass** (iOS 26). Основан на репозитории
[arigandores/anix](https://github.com/arigandores/anix): те же эндпоинты, подпись запросов и парсеры видео.
Не связан с разработчиками Anixart.

## Сборка на GitHub (Мак не нужен)

1. Создайте на github.com новый репозиторий. Лучше **Public**: тогда сборки на macOS бесплатны.
2. Загрузите в него файлы из этого архива: **Add file → Upload files**, перетащите папку `Anix`,
   файлы `project.yml`, `README.md`, `.gitignore`. Нажмите **Commit changes**.
3. Добавьте сборочный скрипт: **Add file → Create new file**, в поле имени введите
   `.github/workflows/build.yml` (слэши создадут папки), вставьте содержимое файла `workflow-build.yml`
   из архива и нажмите **Commit changes**. Этот коммит сразу запускает сборку.
4. Откройте вкладку **Actions → Build IPA**. Сборка идёт 5–10 минут. Когда появится зелёная галочка,
   внизу страницы запуска в разделе **Artifacts** скачайте `Anix-ipa` — внутри `Anix.ipa`.
5. Если сборка красная — скачайте артефакт `build-log` и пришлите текст ошибки: код написан без компилятора,
   первые ошибки вполне ожидаемы.

Повторный запуск: **Actions → Build IPA → Run workflow**.
Если GitHub пишет, что раннера `macos-26` нет, в `build.yml` замените его на `macos-latest`.

## Установка на iPhone (Sideloadly, Windows или Mac)

1. Установите [Sideloadly](https://sideloadly.io) на компьютер (на Windows нужны iTunes и iCloud с сайта Apple, не из Microsoft Store).
2. Подключите iPhone кабелем, разрешите доверие компьютеру.
3. Перетащите `Anix.ipa` в окно Sideloadly, введите свой Apple ID, нажмите **Start**.
4. На iPhone включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**
   (потребуется перезагрузка).
5. Доверьте профиль: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.

Бесплатный Apple ID даёт подпись на **7 дней**, потом приложение нужно установить заново тем же способом
(данные и вход при этом сохраняются). Для автоматического продления есть AltStore и SideStore. Подпись на год —
с платным аккаунтом разработчика ($99).

## Сборка на Mac

Xcode 26, `brew install xcodegen`, `xcodegen`, открыть `Anix.xcodeproj`, выбрать команду подписи, запустить.
Минимальная система — iOS 18. На iOS 18–25 вместо Liquid Glass используется матовый материал.

## Что есть

- Главная: баннеры, подборки (рекомендации, онгоинги, популярное, сейчас смотрят, обсуждают, анонсы), «Показать все» с подгрузкой
- Страница аниме: постер на размытом фоне, рейтинг, списки («Смотрю», «В планах»…), избранное, статистика, жанры, комментарии
- Серии: выбор озвучки и источника, запоминание выбора, отметка просмотренного нажатием на номер серии
- Плеер: AVPlayer со своим управлением на стекле, выбор качества, двойной тап ±10 с, продолжение с места,
  автопереход на следующую серию, картинка в картинке
- Поиск (вкладка поиска iOS 26), закладки со стеклянными чипами, профиль, вход по логину и паролю
- Настройки (шестерёнка в профиле): язык (русский/английский), темы (стандартная, светлая, OLED),
  альтернативное соединение для картинок, «О приложении»
- Страница аниме: «Связанные релизы» (вся франшиза), в английском интерфейсе описание переводится на устройстве
- Настройки: «Очистить кеш» (с выходом из аккаунта)
- Плеер: кнопка +1:30, блокировка интерфейса замком, компактная шкала времени
- Главная: «Продолжить просмотр» с полоской прогресса; нажатие сразу запускает серию (досмотренную — следующую)
- Плеер: в конце серии 5 секунд до следующей (можно отменить или перейти сразу), кнопка картинки в картинке у шкалы времени
- Поиск: фильтры (жанры с режимами, категория, статус, сезон, страна, годы, возраст, сортировка), история запросов,
  подсказки при вводе
- Комментарии: написание, ответы в ветках, спойлер, плюс/минус; оценка релиза звёздами на странице аниме
- Профиль: круговая диаграмма списков, числа открывают соответствующий список
- Регистрация (никнейм с проверкой, почта, код из письма) и редактирование профиля: фото, статус, никнейм,
  соцсети, приватность, смена пароля

## Ограничения

- Код не компилировался при написании (не было Xcode и Swift), возможны мелкие ошибки сборки.
- Прямое воспроизведение работает для Kodik и AniLibria. Остальные источники (Sibnet, VK, RuTube и др.)
  открываются во встроенном веб-плеере. Парсеры можно добавить по образцу `server/parsers/index.js`.
- Нет: улучшения картинки нейросетью, совместного просмотра, AI-помощника, входа через соцсети,
  коллекций, уведомлений.
- Подпись запросов (`Anix/Core/Sign.swift`) — порт `server/sign.js`. Если бекенд сменит алгоритм или версию
  приложения, константы нужно обновить.
