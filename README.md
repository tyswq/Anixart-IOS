Клиент основан на проекте [arigandores/anix](https://github.com/arigandores/anix): те же эндпоинты, подпись
запросов и парсеры видео. С разработчиками Anixart не связан и ими не одобрен.

## Возможности

**Каталог**
- Главная: баннеры, подборки (рекомендации, онгоинги, популярное, сейчас смотрят, обсуждают, анонсы) с подгрузкой
- «Продолжить просмотр» с полоской прогресса: нажатие запускает серию с места остановки
- Поиск с подсказками и историей запросов
- Фильтр каталога: жанры (любой / все / исключить), категория, статус, сезон, страна, годы, возраст, сортировка
- «Связанные релизы» на странице аниме: вся франшиза списком

**Страница аниме**
- Постер на размытом фоне, рейтинг, статистика, жанры
- Избранное и папки («Смотрю», «В планах» и другие) меняются мгновенно, синхронизация идёт в фоне
- Оценка релиза звёздами
- Комментарии: написание, ответы в ветках, спойлеры, плюс и минус

**Плеер**
- Собственное управление на стекле, выбор качества и озвучки, запоминание места остановки
- Двойной тап по краям — перемотка на 10 секунд, кнопка «+1:30» для пропуска опенинга
- Блокировка интерфейса замком
- Автопереход на следующую серию с таймером на 5 секунд
- Картинка в картинке
- Прямое воспроизведение Kodik и AniLibria, остальные источники открываются во встроенном веб-плеере

**Профиль и аккаунт**
- Вход, регистрация (проверка никнейма, код из письма), редактирование профиля: фото, статус, никнейм, соцсети, приватность, пароль
- Круговая диаграмма списков; число в каждой строке открывает соответствующий список

**Настройки**
- Язык: русский и английский (названия релизов оригинальные, описание переводится на устройстве)
- Темы: стандартная, светлая, OLED (полностью чёрная) и Red (чёрная с красным свечением)
- «Альтернативное соединение» для картинок, если обложки не загружаются
- Очистка кеша с выходом из аккаунта

## Установка

Приложение не подписано, поэтому ставится через sideloading. Компьютер с Windows или Mac нужен только для установки.

1. Скачайте `Anix-<версия>.ipa` со страницы [Releases](https://github.com/tyswq/Anixart-IOS/releases/latest).
2. Установите [Sideloadly](https://sideloadly.io). На Windows нужны iTunes и iCloud, скачанные с сайта Apple, а не из Microsoft Store.
3. Подключите iPhone кабелем и разрешите доверие компьютеру.
4. Перетащите `.ipa` в окно Sideloadly, введите свой Apple ID и нажмите **Start**.
5. Включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**, затем перезагрузите iPhone.
6. Доверьте профиль: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.

Обновление: установите новый `.ipa` поверх старого тем же способом, вход и данные сохранятся.

> Бесплатный Apple ID подписывает приложение на **7 дней**, потом его нужно переустановить. Автоматически продлевают подпись
> [AltStore](https://altstore.io) и [SideStore](https://sidestore.io). Подпись на год даёт платный аккаунт разработчика.

Минимальная система — iOS 18. На iOS 26 интерфейс использует Liquid Glass, на iOS 18–25 вместо него матовый материал.

## Сборка своими руками

### На GitHub, без Mac

Сборка идёт на раннерах GitHub Actions (`macos-26`), подпись не нужна.

1. Сделайте форк или загрузите проект в свой репозиторий.
2. Откройте **Actions → Build IPA → Run workflow**. Через 5–10 минут в запуске появятся артефакты:
   `Anix-ipa` (внутри `Anix.ipa`) и `build-log`.
3. Если сборка красная, скачайте `build-log` и найдите строки с `error:`.

**Обновление проекта с телефона.** Загрузите в корень репозитория один `.zip` с проектом
(**Add file → Upload files**). Workflow сам распакует его в файлы, закоммитит и соберёт IPA, а сам zip удалит.

Если коммит из Actions отклоняется, включите **Settings → Actions → General → Workflow permissions → Read and write permissions**.

### На Mac

```sh
brew install xcodegen
xcodegen generate
open Anix.xcodeproj
```

Выберите свою команду подписи и запустите. Нужен Xcode 26.

## Выпуск релиза

1. Добавьте в [CHANGELOG.md](CHANGELOG.md) раздел `## [1.6.0] — 2026-12-01` с описанием изменений
   (по образцу предыдущих) и поднимите `MARKETING_VERSION` в `project.yml`.
2. **Actions → Build IPA → Run workflow**, поставьте галочку **Опубликовать релиз**, при необходимости впишите версию.
3. Workflow соберёт приложение, создаст тег `v1.6.0` и опубликует релиз: заметки берутся из `CHANGELOG.md`,
   файл `Anix-1.6.0.ipa` прикрепляется автоматически. Повторный запуск с той же версией заменяет файл и заметки.

Номер сборки (`CFBundleVersion`) равен номеру запуска workflow.

## Структура проекта

```
Anix/
  AnixApp.swift         точка входа, корневой экран и вкладки
  Core/                 API, модели, подпись запросов, вход, настройки, хранилища
  UI/                   экраны: главная, релиз, поиск, закладки, профиль, комментарии, настройки
  Player/               плеер на AVPlayer и разбор видеоисточников
  Resources/en.lproj/   английская локализация (ключи — русские исходные строки)
  Assets.xcassets/      иконка и ресурсы
project.yml             описание проекта для XcodeGen
CHANGELOG.md            история изменений
```

Проект генерируется XcodeGen, файла `.xcodeproj` в репозитории нет.

## Частые вопросы

**Не загружаются обложки.** Включите **Настройки → Альтернативное соединение**. Картинки пойдут через зеркало,
это помогает, когда провайдер блокирует часть адресов CDN.

**Приложение перестало открываться.** Прошла неделя, и подпись бесплатного Apple ID истекла. Переустановите `.ipa`.

**Не работает видео из какого-то источника.** Прямое воспроизведение есть у Kodik и AniLibria. Остальные источники
открываются во встроенном веб-плеере, и его работа зависит от самого источника.

**На английском часть текста осталась русской.** Описание релиза, жанры и статус переводятся встроенным переводчиком iOS.
При первом запуске система может предложить скачать языковой пакет. Комментарии и названия серий не переводятся.

## Ограничения

- Нет: улучшения картинки нейросетью, совместного просмотра, AI-помощника, входа через соцсети, коллекций,
  уведомлений, скачивания серий.
- Подпись запросов (`Anix/Core/Sign.swift`) — порт `server/sign.js` из оригинального проекта. Если бэкенд сменит алгоритм
  или версию приложения, константы нужно обновить.
